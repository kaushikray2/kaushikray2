# Kaushik Ray

**Embedded systems engineer** — Senior Embedded Software Engineer (Software Defined Vehicle) at GM, and co-founder of **[SiliconBrane Inc.](https://siliconbrane.com)**, an embedded-systems and IoT R&D studio in LaSalle, Ontario, Canada.

I build things end to end: bare-metal firmware, custom PCBs, long-range radio telemetry, and the software and infrastructure around them.

## What I work on

- **Bare-metal firmware** — Renesas RA0E2 / RL78, Nordic nRF52, layered C with no RTOS abstractions where they don't belong
- **LoRa + GNSS telemetry** — long-range, low-power tracking hardware (the [Drover](https://drovertracker.com) off-grid tracker is SiliconBrane's current product, in development)
- **PCB design** — KiCad, from schematic to a board that survives pre-compliance EM testing
- **Self-hosted infrastructure** — Proxmox, Docker, mail, GitLab, and the tooling to run a small R&D shop on my own servers

## Open-source projects

- **[fnirsi-dps150](https://github.com/kaushikray2/fnirsi-dps150)** — Python library, desktop GUI, and browser (Web Serial) controller for the FNIRSI DPS-150 programmable DC power supply. Protocol reverse-engineered and verified on real hardware. MIT.
- **[ilo4-console](https://github.com/kaushikray2/ilo4-console)** — A modern web console for HPE iLO 4 servers, built on the Redfish API. MIT.
